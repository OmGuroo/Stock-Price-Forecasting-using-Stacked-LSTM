# Stock Price Forecasting Using Stacked LSTM

## Project Overview

This project focuses on **stock price forecasting using a Stacked Long Short-Term Memory (LSTM) neural network**. LSTM networks are a type of Recurrent Neural Network (RNN) designed to learn patterns and dependencies from sequential and time-series data.

The objective of this project is to use historical stock-market data to train a deep learning model capable of learning price trends and generating predictions for future stock prices.

## Objectives

- Analyze historical stock-price data.
- Preprocess and normalize time-series data for deep learning.
- Create sequential input data suitable for an LSTM model.
- Build a **Stacked LSTM architecture** for stock-price prediction.
- Train and validate the model using historical data.
- Compare predicted prices with actual prices.
- Visualize the forecasting results.
